## 📝 프로젝트 소개

"아이 주도형 목표 및 보상 앱"은  
아이들이 스스로 계획을 수립하고 목표 달성을 위해 자율적으로 실천할 수 있도록 도와주는 앱입니다.  
부모는 계획 설정에 개입하지 않으며, 단순히 확인하고 보상을 제공하는 역할만 수행합니다.

---

## ✅ 주요 기능

### 👦 아이(Child)
- 스스로 주간/일일 계획을 작성
- 각 계획에 따른 **보상 항목 직접 기입**  
- 계획 달성 시, 달력에 스탬프 표시  
- 스크린타임 목표 설정 + 캡처 업로드  
- 캡처 이미지에서 **대표 어플 3개 추출 및 목표 달성 여부 판단**

### 👨 부모(Parent)
- 자녀 연동 (선택적)  
- 연동된 자녀의 계획 및 진행 상황 확인  
- 보상 여부 `확인`, `보류`, `제공` 중 선택 가능  
- **계획을 직접 편집하거나 삭제할 수 없음**

---

## 🧠 차별화 포인트

- 📌 **부모가 아닌, 아이가 스스로 계획을 세움**  
- 🔒 **부모는 계획을 통제할 수 없고, 확인/보상만 가능**  
- 🎁 **보상 항목도 아이가 직접 작성 → 동기 부여 극대화**  
- 🕹️ 스크린타임을 이용한 **디지털 습관 개선 유도**
